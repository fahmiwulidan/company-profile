## Ringkasan Proyek

**Vellora Digital Company Profile** adalah solusi landing page profil perusahaan berbasis web frontend modern yang dirancang untuk kebutuhan *branding* dan *lead generation*. Website ini menampilkan antarmuka *dark mode* premium, responsif, serta teroptimasi untuk performa tinggi tanpa ketergantungan *framework* luar.

> [!NOTE]
> Repository ini dikembangkan menggunakan struktur *pure frontend stack* (HTML, CSS, JS) dan di-deploy secara otomatis melalui infrastruktur **Vercel**.

---

## Teknologi Utama

| Layer | Teknologi | Deskripsi |
| :--- | :--- | :--- |
| **Structure** | HTML5 | Semantik markup terstruktur dan teroptimasi SEO |
| **Styling** | CSS3 | Custom Dark-Theme UI, CSS Grid, Flexbox, & CSS Variables |
| **Interactivity** | JavaScript (ES6+) | Logika interaksi antarmuka dan manipulasi DOM |
| **Deployment** | Vercel | Infrastructure as a Service untuk hosting instan & CI/CD |

---

## Fitur Unggulan

- **Desain Modern Dark-Theme** — Visual estetis dengan gaya *grid background* dan tipografi bersih berstandar industri.
- **Responsif Sepenuhnya** — Layout adaptif yang nyaman diakses dari perangkat mobile, tablet, hingga desktop.
- **Performa Ringan (Zero Dependency)** — Akses muat halaman instan karena tidak menggunakan library/framework eksternal yang berat.
- **Call-to-Action (CTA) Terintegrasi** — Tombol interaktif untuk konsultasi langsung dan navigasi portofolio.
- **Struktur Kode Modular** — Pemisahan berkas HTML, CSS, dan JS yang rapi serta mudah dirawat.

## Panduan Memulai

### 1. Kloning Repositori
```bash
git clone (https://github.com/fahmiwulidan/company-profile.git)
cd company-profile
```

### 2. Jalankan Secara Lokal
Proyek ini berbasis kode native web. Anda dapat langsung membuka berkas `index.html` pada browser pilihan Anda atau menggunakan ekstensi **Live Server** di VS Code:

```bash
npx live-server
```
